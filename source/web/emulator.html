  • A page button opens the first view of its page; press it again for the next view (the dots at the top right show the views)Un bouton de page ouvre la première vue de sa page ; appuyer encore : vue suivante (les points en haut à droite montrent les vues)

PLAYING LIVEJOUER EN LIVE
  • SEL opens: FILTER / COLOUR → FILTER MOD → PERFORM (4 macros, morph, pads) → MORPH X/Y → FX LIVE → MACROS → MORPH A/BSEL ouvre : FILTRE / COULEUR → MOD DU FILTRE → PERFORM (4 macros, morph, pads) → MORPH X/Y → FX LIVE → MACROS → MORPH A/B
  • Hold LFO and turn a knob: LFO 2 goes on what that knob sets (LFO 1 or 2: SYSTEM)LFO maintenu + un potard : le LFO 2 va sur ce que règle le potard (LFO 1 ou 2 : SYSTEM)
  • Hold FX: FX PADS, the keys play effects (white: wobble speed, black: stutter, tape stop…)FX maintenu : FX PADS, les touches jouent des effets (blanches : vitesse du wobble, noires : stutter, tape stop…)
  • PLAY held = HOLD (the note stays, hands free for the wobble); REC = TAP tempoPLAY maintenu = HOLD (la note reste, mains libres pour le wobble) ; REC = TAP tempo
  • Held buttons (mouse): OCT- 1 s = UNDO, OCT+ = REDO, SAVE = UNDO / REDO window, HOME = PANIC, GLO = CLASSIC / SHIFT, SEL = A/BBoutons maintenus (souris) : OCT- 1 s = UNDO, OCT+ = REDO, SAVE = fenêtre UNDO / REDO, HOME = PANIC, GLO = CLASSIC / SHIFT, SEL = A/B
  • OCT- + OCT+ together: everything offOCT- + OCT+ ensemble : tout couper
